# Airstrike

Мод для Minecraft 1.21.1 на NeoForge. Добавляет удары с воздуха: дрон-камикадзе в духе «Шахеда»,
барражирующий боеприпас в духе «Ланцета», крылатую ракету, реактивную систему залпового огня в духе «Града»,
бомбардировщик B-2 с бетонобойной бомбой и межконтинентальную ракету с ядерной боевой частью. От ударов защищает
зенитный ракетный комплекс.

Мод сделан для сборки «All of Create Aeronautics», но работает и без неё. Если стоит Create Aeronautics,
целью можно выбрать летательный аппарат, в том числе в полёте.

Блок равен метру: снаряды и пусковые сделаны в настоящую величину, радиусы ядерного удара рассчитаны
по справочным данным.

## Установка

Проще всего играть в сборке «Airstrike Pack» (Create, Create Aeronautics, Distant Horizons, шейдеры): она сама
обновляется при каждом запуске игры, вместе с Airstrike. Как её поставить — в [README сборки](https://github.com/zentixua/airstrike-pack#установка).
Без сборки:

1. Нужны Minecraft 1.21.1 и NeoForge 21.1.250 или новее. Других обязательных модов нет.
2. Скачайте `airstrike-<версия>.jar` со страницы [Releases](https://github.com/zentixua/airstrike/releases/latest)
   и положите в папку `mods`. Прежний jar Airstrike из `mods` удалите.
3. Мод нужен и на сервере, и у каждого игрока, причём один и тот же файл. С другой версией мода игра к серверу
   не подключится.

Сборке «All of Create Aeronautics» нужно не меньше 8 ГБ памяти, а если в компьютере 32 ГБ, лучше дать 12 ГБ.
В Prism Launcher: правой кнопкой по сборке, «Изменить», «Настройки», «Java», максимум памяти 8192 МБ
(или 12288 МБ).

Если в мире стоял старый датапак Airstrike или Shahed, мод при первом запуске сам выключит его и перенесёт
настройки. Отдельный пакет звуков не нужен.

## Совместимость

- Create Aeronautics и Sable необязательны. С ними целью можно выбрать летательный аппарат, взрывы ломают
  и толкают аппараты.
- Distant Horizons 3.3 или новее необязателен. С ним карта наведения показывает дальний рельеф, а изменения
  от ударов сразу видны в дальнем рельефе DH.
- С Sound Physics Remastered глушение звука за препятствиями делает он, мод добавляет только оглушение
  от взрыва.
- Ядерная картинка рисуется и под шейдерами Iris.

## Сборка из исходников

Нужна Java 21.

```sh
python3 tools/fetch_runtime_mods.py                # Create, Sable и Create Aeronautics для GameTest
cd mod
./gradlew build                                    # сборка и юнит-тесты, jar в build/libs
./gradlew runGameTestServer -PmcModsDir=run/ci-mods
```
