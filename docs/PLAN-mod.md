# План: Airstrike как мод NeoForge (27.09.2026)

Решение Артёма: сразу полный перевод, без промежуточных стадий. Датапак и пакет звуков уходят на покой
(переезжают в `legacy/`, история в git), мод повторяет всё, что они умели, и добавляет новое.

## Стек (по внешним источникам)
| Что | Версия | Почему |
|---|---|---|
| Minecraft | 1.21.1 | сборка «All of Create Aeronautics» |
| NeoForge | 21.1.250 (компиляция) | ровно как в сборке; мод работает и на более новых 21.1.x |
| ModDevGradle | 2.0.147 | официальный плагин для мода на одну версию (MDK NeoForgeMDKs/MDK-1.21.1-ModDevGradle) |
| Parchment | 2024.11.17 | имена параметров |
| Java | 21 | требование 1.21.1 |
| sable-companion | 1.6.0, внутри jar (jarJar) | официальная лёгкая библиотека совместимости Sable (MIT). Без Sable работает заглушка, с Sable — настоящие аппараты. Sable 2.0.5 не принимает companion новее 1.6.0 |

Жёстких зависимостей, кроме NeoForge, нет: ни GeckoLib, ни Veil, ни SnAssets. Модели — ванильные `LayerDefinition`,
звуки — свои (синтез `tools/synth_mod_sounds.py`), эффекты — клиентские частицы, камера, звук.

Sable без своего кода: ванильный `Explosion` уже ломает блоки аппаратов и толкает их (миксин Sable
`ExplosionMixin`), поэтому основной взрыв делаем через `ServerLevel.explode` с нашим `DamageSource` и калькулятором.

## Интерфейс
- **Пульт наведения** (один предмет): ПКМ — бинокль с прицельной маркой, дальностью и типом цели;
  колесо — оружие; ЛКМ — пуск; Shift+ПКМ — экран: оружие, количество (1–30), разброс (0–150), цель
  (куда смотрю / вокруг меня / игрок из списка).
- HUD: снаряды в полёте и время подлёта у того, кто пустил; «ВОЗДУШНАЯ ТРЕВОГА» и сирена у тех, по кому бьют.
- Команды `/airstrike` (для операторов и автоматизации), экран настроек мода.

## Проверка
- Юнит-тесты: наведение, Доплер, бурение.
- GameTest (`runGameTestServer`, без окна): полёт и подрыв каждого оружия, бурение, залп, прицел.
- CI в GitHub Actions: сборка, тесты, GameTest, jar как артефакт.

- В `mod/` — каркас ModDevGradle и начало кода: регистрации, настройки, `Loadout`, `Target`/`TargetTracker`/`TargetPicker`,

  в той сессии сеть не пускала на maven NeoForge/Mojang, а GitHub Actions не запускал задачи. Классы, на которые
  ссылается код (`DroneEntity`, `CruiseMissileEntity`, `BomberEntity`, `BunkerBusterEntity`, `AirstrikeNetwork`, …), ещё не написаны.
- Параметры полёта из датапака (переведены в блоки/градусы): шахед 2.1 б/т, пике до 3.0 (+0.04/т), крейсер ≥ рельеф(15/30/45)+18,
  ≥ цель+30, тангаж ω=0.12·ошибка, |ω|≤1.2°/т, |Δω|≤0.15; пике — дуга ω=3.2·v·(угол на цель−тангаж)/d, |ω|≤4, |Δω|≤0.25;
  переход в пике при угле на цель ≥18°; подрыв при d ≤ v+4.3; таймаут 900. Курс: ω=0.15·ошибка, ≤3°/т, Δ≤0.3; не рулить ближе 8 блоков.
  Ракета 11.5 б/т; бреющий ≥ рельеф(30/60/90)+12 и ≥ цель+12, ω=0.3·ошибка, ≤8, Δ≤1.8; в 160 блоках — горка (−20°, если старт ≥185)
  до угла 24° или цель+32, затем дуга ≤16, Δ≤3.5, +0.1/т до 12.5; подрыв d ≤ v+6.5; таймаут 700; пуск через 100 т после сирены.
  B-2: цель+170, старт 260 позади, 12 б/т по прямой, сброс в 85 блоках по горизонтали, уходит через 120 т.
  Бомба: 6 б/т +0.3 до 12.5, дуга ≤7, Δ≤0.8, подрыв d ≤ v+5.3, таймаут 300; бурение — `bunker/step.mcfunction`.
- Находки: `Level.clip` с Sable возвращает попадание в аппарат в координатах плота; ванильный `Explosion` сам ломает и толкает
  аппараты (миксин Sable), поэтому основной взрыв — `level.explode(...)`.
