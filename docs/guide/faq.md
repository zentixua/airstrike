# Вопросы и неполадки

## Что значит сообщение

| Сообщение | Что делать |
|---|---|
| «Не хватает боеприпасов: Шахед-136 — нужно 5, есть 2» | скрафти ещё или уменьши залп на экране пульта ([боеприпасы](munitions.md)) |
| «ENOTzRPG не замечен: по игроку и аппарату бьют, только когда его видите вы…» | найди его глазами, в бинокль или камерой снаряда, либо пусть его увидит кто-то из команды ([разведка](rules.md#разведка)) |
| «⌖ Цель: место, где ENOTzRPG видели 12 с назад» | удар пойдёт в место, где его видели, а не за ним |
| «Пусковую негде поставить: по курсу пуска постройки. Заход издалека.» | ничего страшного, снаряд прилетит издалека; чтобы видеть пуск, отойди на открытое место |
| «Пуск не удался: рядом с целью мир не загружен» | сервер не успел загрузить район цели; боеприпас вернулся, попробуй ещё раз |
| «Цель не найдена» | под прицелом ничего нет или цель дальше 400 блоков; бей по карте |
| «Слишком далеко: удар по карте — не дальше 10000 блоков» | выбери место ближе |
| ««Ракета» не пролетит маршрут: 34 км, дальность 30 км» | убери или сдвинь точки маршрута |
| «Оружие «РСЗО» летит без маршрута» | маршрут берут только шахед, ракета и «Ланцет» |
| «Пульт работает только у операторов» | в мире выключена настройка `designator_for_everyone`; спроси хозяина мира |
| «Ядерный удар — только для операторов» | так по умолчанию ([ядерный удар](nuke.md#кто-может-пустить)) |
| «Слишком много ударов в работе (10, предел 10)» | хозяин мира поставил предел; дождись попаданий или дай [отбой](designator.md#отбой) |
| «☢ Подрыв задерживается: догружается место удара» | подрыв случится, как только сервер загрузит место |
| «В мире с потолком (Незер) удар по карте недоступен» | в Незере бей из бинокля |

## Неполадки

**Не пускает на сервер, пишет про разные версии мода.** У тебя и у сервера разные версии Airstrike. В сборке
«Airstrike Pack» мод обновляется сам при запуске игры: перезапусти игру из лаунчера. Без сборки скачай тот же jar,
что на сервере, со страницы [Releases](https://github.com/zentixua/airstrike/releases/latest), а старый удали.

**Карта вдали пустая.** Без Distant Horizons карта показывает только загруженные чанки. С ним рельеф появляется
по мере того, как он его считает. Ударить по пустому месту всё равно можно.

**Снаряд не идёт за игроком.** За движущейся целью идут только шахед и «Ланцет», и только пока цель в кадре
их камеры (`N`). Остальное оружие бьёт туда, где цель была при пуске.

**Не слышно звуков мода.** Проверь ползунок громкости «Окружение».

**Игра тормозит при ядерном взрыве.** Поставь «Подробность ядерного гриба» на низкую. Сборке нужно не меньше 8 ГБ
памяти, при 32 ГБ в компьютере лучше дать 12.

**ЗРК не стреляет.** Проверь, что над ним открытое небо, в нём есть ракеты (ПКМ пустой рукой покажет запас), рядом
есть игрок, а цель чужая: свои снаряды и снаряды своей команды он не трогает. МБР и «Град» он не сбивает.

**Камера пишет «Нет снарядов в полёте».** Камера показывает только твои снаряды, которые уже пущены.

**Удар по своей базе.** Взрыв бьёт всех: проверь режим цели на экране пульта перед огнём. «Вокруг меня» бьёт туда,
где ты стоишь.
