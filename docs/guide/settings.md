# Настройки и клавиши

Настройки открываются в игре: «Моды → Airstrike → Настроить» или кнопка «Настройки» на экране пульта. У каждого
пункта есть подсказка.

## Свои настройки

Они у каждого игрока свои и лежат в `config/airstrike-client.toml`.

| Настройка | По умолчанию | Что задаёт |
|---|---|---|
| Сила тряски камеры | 1 | 0 — без тряски; прицел не сбивается, трясётся только камера |
| Яркость вспышки | 1 | 0 — без вспышки взрыва на экране |
| Снаряды в полёте на экране | вкл | список своих снарядов и метки в мире |
| Камера снаряда сама при пуске | выкл | при каждом пуске камера сама показывает пуск, полёт и попадание |
| Кратность бинокля | 4 | от 1,5 до 10 |
| Подробность ядерного гриба | средняя | ниже — легче для слабого компьютера |
| Оглушение и звон в ушах | вкл | глухота после близкой ударной волны |
| Глушить звук вдали и за преградой | вкл | с модом Sound Physics Remastered это делает он |
| Рельеф карты заранее | вкл | карта открывается сразу, пока пульт в инвентаре |

Звуки мода идут по ползунку громкости «Окружение», чёрный дождь — по ползунку «Погода».

## Клавиши

«Настройки → Управление → Airstrike»:

| Клавиша | По умолчанию |
|---|---|
| Пуск (в бинокле пульта) | ЛКМ |
| Камера снаряда | `N` |
| Карта наведения | `,` |
| Второй ключ (подтвердить ядерный пуск рядом) | `.` |
| Открыть пульт | не назначена |

Бинокль (ПКМ) и экран пульта (Shift+ПКМ) работают от обычной клавиши «Использовать».

## Настройки мира

Их меняет хозяин мира: в одиночной игре — ты (файл `saves/<мир>/serverconfig/airstrike-server.toml`), на сервере —
его владелец. Самые нужные:

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `launch.designator_for_everyone` | вкл | пульт работает у всех игроков, а не только у операторов |
| `launch.max_salvo`, `max_spread` | 30, 150 | наибольший залп и разброс |
| `launch.map_range` | 10000 | дальность удара по карте, блоков |
| `launch.sight_rules`, `sight_memory` | вкл, 30 | разведка: бить только по замеченным; сколько секунд помнится замеченное |
| `launch.map_players` | вкл | игроки на карте пульта |
| `launch.drone_flight_time`, `missile_flight_time`, `bomber_flight_time` | 50, 30, 40 | время полёта до удара, секунд |
| `launch.loiter_time` | 25 | сколько «Ланцет» кружит до пике, секунд |
| `warheads.*_power` | 12, 20, 7, 8, 20 | сила взрыва шахеда, ракеты, «Града», «Ланцета», бомбы (у ТНТ 4) |
| `world.block_damage`, `fire`, `shatter_glass`, `siren` | вкл | разрушения, пожары, стёкла, сирена |
| `nuclear.enabled`, `ops_only` | вкл, вкл | ядерное оружие есть; пускать его могут только операторы |
| `nuclear.second_key_distance`, `second_key_window` | 16, 30 | второй ключ: с какого расстояния и сколько секунд ждать |
| `nuclear.effects_scale` | 1.0 | масштаб радиусов ядерного удара |
| `grid.enabled`, `restore_minutes` | вкл, 15 | блэкаут; через сколько минут возвращается свет |
| `air_defense.radar_range`, `engage_range`, `kill_probability` | 3000, 1500, 0.8 | ЗРК: дальность радара и огня, вероятность сбить |
| `visibility.far_range` | 8000 | докуда видно и слышно снаряды и взрывы, блоков |
