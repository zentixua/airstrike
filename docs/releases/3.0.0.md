For Minecraft 1.21.1 and NeoForge 21.1.259 or newer. Not network-compatible with 2.10.3 and earlier: update the mod on the server and for every player.

## Airstrike is now Incoming

The mod has a new name, and everything that carried the old one changes with it:

- the mod id and namespace: `airstrike` → `incoming`, for example `/give @s incoming:strike_designator`;
- the command: `/airstrike` → `/incoming`;
- the jar: `incoming-3.0.0.jar`;
- the settings files: `incoming-server.toml` and `incoming-client.toml`.

Worlds from earlier versions keep the mod's blocks, items and entities, radiation doses, the damage of past nuclear strikes and the state of the power grid. These do not carry over on their own:

- World settings. Before the first start, rename `serverconfig/airstrike-server.toml` in the world folder (`saves/<world>/` in singleplayer, the world folder on a server) to `incoming-server.toml`. Otherwise the world starts with the default settings.
- Your own settings. Rename `config/airstrike-client.toml` to `incoming-client.toml`.
- Key bindings of the mod go back to their defaults.
- Command blocks, functions and scripts that call `/airstrike` need `/incoming`.

## Changes

- Items, screens, setting descriptions on the settings screen and `/incoming help` are in English, with a full Russian translation. Comments in the config files and log messages are in English.
- Every setting on the settings screen has a description. 33 of them had none, and the screen showed the Russian comment from the config file.
- Projectile numbers show as `#` in English and `№` in Russian.
- The player guide is in English, with the Russian version in `docs/guide/ru`.

## Installation

Remove the old `airstrike-*.jar` from the `mods` folder and put `incoming-3.0.0.jar` in its place. The server and every player need the same file; see the [README](https://github.com/zentixua/incoming#installation).
