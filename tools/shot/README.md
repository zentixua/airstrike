# Съёмка по сцене (`tools/shot`)

Камера плана решается до игры: сцена (карта рамки, пути снарядов, удары, дым, туман края прорисовки, облака) — в
памяти, камера — путь тела (FPV, кинодрон, оператор с камерой в руках, штатив, следящая камера пуска), который лучше
всех по одной мере, черновой кадр — лучами по блокам за доли секунды. Игра (вывод `ReplayFilm`, съёмка replayscan)
только рисует готовый путь, а её проверка кадров сверяется с тем, что мера обещала (`predicted.jsonl`).

Почему так — записка `/mnt/project-files/filming-rethink/` (13.10.2026).

```sh
uv run tools/shot/shot.py plan <план>.events.jsonl --regions <мир>/region --out <папка> [--styles fpv,tripod]
uv run tools/shot/shot.py demo --out <папка>          # тестовый квартал без карты
uv run --with numpy --with scipy --with pillow python -m unittest discover -s tools/shot/tests
```

- Объект плана — по `trailer_shots.json` (те же правила, что `Coverage` трейлера: `impact:W[@x,z][#n]`, `first:W`,
  `framed:W`, `flight:W`, `launch:W@x,z[,r]`, `nuke`), иначе `--subject`, иначе `auto`. Окно — отметки `start`…`end`
  журнала, удар — с запасом 20 тиков.
- Мера (`shotlib/solve.py: evaluate`), меньше — лучше: объект в кадре и в безопасной зоне, не за блоками, дымом,
  туманом и облаками, читаемого размера; удар в кадре и виден первые 12 тиков; камера не в блоках и с воздухом
  вокруг, на высоте своего тела; скорость, разгон, рывок и повороты взгляда в пределах тела; у FPV — летит туда, куда
  смотрит, крен и кивок — из ускорения; низ кадра — не в чанках, которых нет. `own` в отчёте — камера сценария той же
  мерой: так видно, что план поправил.
- Поиск — кросс-энтропийный по опорным точкам B-сплайна: семена по телу (проходы с 16 курсов и трёх расстояний,
  места штатива по кругу, погоня), лучшие сгибаются пробами вокруг лучшего.
- Выдача плана: `<план>/<тело>/camera.jsonl` — поза на тик повтора (`t`, `pos`, `yaw`, `pitch`, `roll`, `fov` по
  вертикали; углы — как у Minecraft: курс 0 — юг, тангаж плюс — вниз, крен плюс — влево), `path-camera.json` — камера
  `path` плана replayscan, `predicted.jsonl`, `report.json`, `summary.txt`; с `--previs` — `sheet.jpg`, `previs.mp4`.
- Карта рамки (`world.npz`) — данные карты: остаётся на машине, где лежит мир (Zearth наружу не выносится; наружу —
  `summary.txt` и черновые кадры).

Модули `shotlib`: `world` — блоки из файлов регионов (роды: воздух, непрозрачный, листва и стекло, вода, неизвестный
чанк), `scene` — журнал EventLog, дым ударов (гауссовы клубы, свет сквозь них — точным интегралом), `subject` — выбор
объекта и окна, `camera` — углы и проекция Minecraft, тела камер, `solve` — мера и поиск, `previs` — черновой кадр,
`export` — выдача, `demo` — тестовый квартал.
